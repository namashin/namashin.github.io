China Eastern Airlines Ground Service Multi-Skilled Personnel Dispatch Optimization Project

Overview

Developed an interpretable scheduling system for multi-skilled personnel in aviation ground services, utilizing a collaborative framework based on a Deep Value Network (DVN) and a Large Language Model (LLM).

Roles

[Role] - Algorithm Researcher / Software Engineer

Results

[Achievements] - DVN-LLM Collaborative Model Development: Leveraged DVN to efficiently evaluate values and filter candidate solutions based on continuous operational state features such as flight status, personnel distribution, and task time windows. Combined with the LLM's semantic reasoning capabilities, achieved automated scheduling that balances optimization efficiency with strict rule compliance. - Explainable AI via RAG and CoT: Integrated Chinese Civil Aviation Regulations (CCAR), Standard Operating Procedures (SOP), and historical scheduling cases to build a long-and-short-term dual-layer memory retrieval system (RAG). Introduced a hierarchical Chain-of-Thought (CoT) reasoning process, breaking the black-box limitations of traditional reinforcement learning. Simultaneously generated standardized dispatch results alongside natural language explanatory texts detailing regulatory bases and reasoning for personnel selection. - Strict Application of Business Rules and Constraints: Utilized the LLM's text parsing capabilities to integrate complex rigid constraints—such as continuous working hour limits, mutually exclusive skill matching, and downward-compatible substitution relationships across different role hierarchies—into the system. This method effectively avoided non-compliant dispatching and enhanced safety margins. - Dynamic Adaptation and Simulation Validation: Addressed abnormal scenarios such as flight delays, temporary gate changes, and sudden personnel shortages through closed-loop simulation testing using authentic historical data. This validated the system's robustness and highly efficient real-time response capabilities during global task reconfiguration.
