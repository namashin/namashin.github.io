选择TCP/IP的原因是，传感器发送的数据是不能容忍丢失或顺序混乱的重要信息.

因此，我们优先考虑数据通信的可靠性，并选择TCP协议来确保数据能够被可靠传输.

TCP支持在通信中出现数据丢失时的重传功能，并能保持发送数据的顺序，是在实现实时性与稳定性之间最佳的选择。 具体来说，传感器通过TCP发送数据，服务器端使用TCP套接字实时接收数据.

接收的数据包会被解析，提取出传感器ID、测量值等必要的信息.

此外，我们利用Golang的并发处理功能（goroutines和channels），高效地处理了大量的连接，从而确保了系统的可扩展性。 主要成果是数据吞吐量提升了40% (BenchMark), 显著缩短了处理时间，实现了实时性.

通过高可靠的数据通信，实现了从旧系统（基于VB和C语言构建）的平稳迁移.

通过这个项目，我们成功结合了TCP/IP协议的高可靠通信与Golang的高效并发处理，显著提升了系统整体的性能与稳定性 .

中国东方航空地服多技能人员派工调度优化项目

Overview

针对航空地面服务复杂的时空耦合与法规约束问题，构建了基于深度价值网络（DVN）与大语言模型（LLM）协同的多技能人员可解释调度系统。

Roles

【角色】 - 算法研发 / 软件工程师

Results

【成果与业绩】 - 研发 DVN-LLM 协同模型：利用 DVN 对航班运行状态、人员分布、任务时窗等连续状态特征进行高效的价值评估与候选方案筛选。结合 LLM 的语义推理能力，实现了兼顾优化效率与规则合规性的自动化调度。 - 基于 RAG 与 CoT 的可解释性决策：整合《中国民用航空规章》（CCAR）、标准操作程序（SOP）及历史排班案例，构建了长短时双层记忆检索体系（RAG）。引入层次化思维链（CoT）推理流程，打破了传统强化学习的黑盒局限。在输出标准化派工结果的同时，同步生成包含规则依据和人员选择理由的自然语言解释文本。 - 严格落实业务规则与约束：通过大模型的文本解析能力，将员工连续作业时长限制、技能资质匹配互斥以及不同角色层级的向下兼容替代关系等复杂硬性约束融入系统中。该方法有效避免了违规派单，提升了安全冗余。 - 动态环境适应与仿真验证：针对航班延误、临时换机位及突发人员短缺等异常场景，通过真实历史数据的闭环仿真测试，验证了系统在全局任务重构中的鲁棒性与高效实时响应能力。

研究概要

论文已被ICIC 2026（International Conference on Intelligent Computing）录用，并接受Poster形式展示。 本研究将航空地面运行中的实时多技能人员派工问题建模为半马尔可夫决策过程（SMDP），提出一种结合价值学习与基于Hungarian Algorithm的最优近似分配方法的混合框架，并进一步引入gated Large Language Model（LLM）模块以处理非结构化输入。
